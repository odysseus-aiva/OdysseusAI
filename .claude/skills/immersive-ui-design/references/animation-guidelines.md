# Animation Guidelines

- Animation must clarify state, hierarchy, or interaction.
- Prefer subtle transitions over continuous decorative movement.
- Keep routine transitions fast and responsive.
- Use spring motion only when it adds natural feedback.
- Avoid animating every element simultaneously.
- Avoid heavy effects that degrade rendering performance.
- Animate transform and opacity where possible.
- Support prefers-reduced-motion.
- Reuse shared animation tokens and primitives.
- Validate animations on desktop and mobile.
